# OZO PowerShell Module

## Installation
This module is published to the [PowerShell Gallery](https://learn.microsoft.com/en-us/powershell/scripting/gallery/overview?view=powershell-5.1). Install it for the current user with:

```powershell
Install-Module OZO -Scope CurrentUser
```

## Usage
Import this module in your script or console to make the functions available for use:

```powershell
Import-Module OZO
```
