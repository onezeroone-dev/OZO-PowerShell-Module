# Test-OZOLocalAdministrator
This function is part of the [OZO PowerShell Module](https://github.com/onezeroone-dev/OZO-PowerShell-Module/blob/main/README.md).

## Description
Returns _True_ if the current user is a local administrator and otherwise _False_.

## Syntax
```
Test-OZOLocalAdministrator
```

## Parameters
None.

## Examples
`````powershell
Test-OZOLocalAdministrator
True
`````

## Outputs
`System.Boolean`
